# AI 사용 기록

이번 과제 진행 중 AI를 다음과 같은 목적으로 사용했다.

## 1. 배포 순서 정리

EC2에 접속한 뒤 어떤 명령을 어떤 순서로 실행해야 하는지 정리하는 데 AI를 사용했다. 특히 Mac 로컬 터미널과 EC2 터미널에서 실행해야 하는 명령을 구분하는 데 도움을 받았다.

## 2. Nginx 리버스 프록시 설정

React 정적 파일 요청과 Spring Boot API 요청을 분리하기 위해 Nginx 설정 방향을 확인했다. `/posts`, `/comments`, `/users`, `/h2-console` 요청을 backend로 전달하고, 나머지 요청은 frontend로 전달하는 구조를 AI와 함께 점검했다.

## 3. Dockerfile 및 Docker Compose 구성

React와 Spring Boot 각각에 멀티스테이지 Dockerfile을 작성하고, Docker Compose에서 backend, frontend, nginx를 함께 실행하는 구조를 만드는 데 AI를 활용했다.

## 4. 배포 오류 해결

배포 중 발생한 오류를 분석하는 데 AI를 사용했다.

- `405 Not Allowed`
- `no space left on device`
- Gradle build daemon 종료
- Docker Nginx upstream DNS 오류
- host Nginx와 Docker Nginx의 80 포트 충돌
- GitHub push 인증 및 rebase 충돌

## 5. 기능 오류 수정

브라우저 테스트 중 발견한 기능 오류를 수정하는 데 AI를 활용했다.

- 게시글 조회수 증가 오류
- 댓글 수정 API 라우팅 오류
- 게시글 작성 API 라우팅 오류
- 아이템 가격 차감 오류
- 아이템 장착 이미지 위치 조정
- 새싹 머리핀 이미지 배경 제거

## 6. 제출 문서 작성

과제 제출물에 필요한 항목을 정리하는 데 AI를 사용했다.

- Git repo 주소
- 배포 주소
- EC2 환경 정보
- 환경 변수
- 작업 과정
- AWS 스크린샷 목록
- 회고
- AI 사용 기록

AI의 답변을 그대로 제출하기보다는, 실제 터미널 실행 결과와 브라우저 테스트 결과를 바탕으로 내용을 확인하고 수정하면서 최종 문서를 작성했다.
