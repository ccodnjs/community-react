# 프론트 성능 개선 기본 세트

## 1. 작업 목적

게시글 목록과 여러 페이지를 한 번에 불러오면 첫 화면 로딩이 무거워질 수 있다. 특히 `토마토 키우기`는 게시글 이미지, 프로필 이미지, 여러 페이지 컴포넌트를 함께 사용하기 때문에 화면 전환과 이미지 로딩 부담을 줄이는 작업이 필요했다.

이번 작업에서는 프론트엔드 반응성을 높이기 위해 다음 세 가지를 적용했다.

- 페이지 단위 코드 분리
- 이미지 lazy loading 및 비동기 디코딩
- 게시글 카드 불필요한 리렌더 방지

## 3. 페이지 단위 코드 분리

기존에는 `App.jsx`에서 모든 페이지 컴포넌트를 즉시 import했다. 이 경우 사용자가 아직 방문하지 않은 페이지 코드까지 초기 번들에 포함될 수 있다.

이를 `React.lazy`와 `Suspense`로 변경해 필요한 페이지를 방문할 때 해당 페이지 코드를 불러오도록 개선했다.

```jsx
import { lazy, Suspense } from "react";

const FarmersPage = lazy(() => import("./pages/FarmersPage"));
const LoginPage = lazy(() => import("./pages/LoginPage"));
const MyPostsPage = lazy(() => import("./pages/MyPostsPage"));
const PasswordEditPage = lazy(() => import("./pages/PasswordEditPage"));
const PostDetailPage = lazy(() => import("./pages/PostDetailPage"));
const PostEditPage = lazy(() => import("./pages/PostEditPage"));
const PostWritePage = lazy(() => import("./pages/PostWritePage"));
const PostsPage = lazy(() => import("./pages/PostsPage"));
const ProfilePage = lazy(() => import("./pages/ProfilePage"));
const SignupPage = lazy(() => import("./pages/SignupPage"));

function PageFallback() {
  return <div className="page-loader">페이지를 불러오는 중...</div>;
}
```

라우터는 `Suspense`로 감싸서 페이지 코드가 로딩되는 동안 fallback UI를 보여주도록 했다.

```jsx
export default function App() {
  return (
    <Suspense fallback={<PageFallback />}>
      <Routes>
        {/* routes */}
      </Routes>
    </Suspense>
  );
}
```

## 4. 이미지 로딩 최적화

이미지는 화면 렌더링을 무겁게 만드는 대표적인 요소다. 게시글 이미지와 프로필 이미지는 사용자가 실제로 볼 때 로딩되어도 충분하므로 `loading="lazy"`를 적용했다.

또한 이미지 디코딩이 메인 렌더링 흐름을 막지 않도록 `decoding="async"`를 함께 적용했다.

```jsx
<img
  src={postImage}
  alt="게시글 이미지"
  className="post-thumbnail"
  loading="lazy"
  decoding="async"
/>
```

프로필 이미지에도 같은 방식으로 적용했다.

```jsx
<img
  src={authorProfileImage}
  alt={`${authorName} 프로필`}
  loading="lazy"
  decoding="async"
/>
```

## 5. 게시글 카드 리렌더 최적화

게시글 목록에서는 카드가 여러 개 반복된다. 검색어 입력, 메인 문구 애니메이션, 사용자 정보 갱신 같은 상태 변화가 있을 때 모든 카드가 불필요하게 다시 렌더링될 수 있다.

`PostCard`를 `memo`로 감싸서 props가 바뀌지 않은 카드는 다시 그리지 않도록 했다.

```jsx
import { memo } from "react";

function PostCard({ post }) {
  // 게시글 카드 렌더링
}

export default memo(PostCard);
```

## 6. 기대 효과

- 첫 화면에서 한 번에 불러오는 JavaScript 양 감소
- 이미지가 많은 목록 화면에서 초기 렌더링 부담 감소
- 게시글 카드가 많은 화면에서 불필요한 리렌더 감소
- 사용자가 체감하는 스크롤과 화면 전환 반응성 개선

## 7. 검증 내용

코드 기준으로 다음 사항을 확인했다.

- `App.jsx`에서 페이지 컴포넌트가 `React.lazy`로 분리됨
- 이미지 태그에 `loading="lazy"` 또는 `decoding="async"`가 적용됨
- `PostCard`가 `memo(PostCard)`로 export됨

로컬에서 `pnpm build` 검증을 시도했지만, 현재 환경에서 `registry.npmjs.org` DNS 조회가 실패해 의존성 설치 단계에서 중단되었다. 네트워크가 정상인 환경 또는 EC2 배포 환경에서 다시 빌드 검증이 필요하다.
